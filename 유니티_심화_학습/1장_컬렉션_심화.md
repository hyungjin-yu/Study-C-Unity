# Chapter 1: 유니티 컬렉션 심화 및 실무 활용

유니티에서 데이터를 다룰 때 가장 많이 사용되는 `List`, `Dictionary`, `Queue`, `Stack`의 심화 활용법과 성능 최적화에 대해 학습합니다.

---

## 1. List<T> 심화: 데이터 정렬과 검색

`List<T>`는 단순히 데이터를 담는 용도를 넘어, 유니티 인스펙터와 연동하여 가장 강력하게 사용됩니다.

### 데이터 정렬 (Sorting)
단순 수치뿐만 아니라, 객체의 특정 속성(예: 공격력, 이름)을 기준으로 정렬할 수 있습니다.

```csharp
using System.Collections.Generic;
using System.Linq; // LINQ 사용을 위해 필수
using UnityEngine;

public class Item {
    public string name;
    public int price;
}

public class ListExample : MonoBehaviour {
    public List<Item> inventory = new List<Item>();

    void Start() {
        // 1. 기본 Sort (람다식 활용)
        inventory.Sort((a, b) => a.price.CompareTo(b.price)); // 가격 오름차순
        
        // 2. LINQ를 이용한 정렬 (새로운 리스트 반환)
        var sortedList = inventory.OrderByDescending(x => x.price).ToList(); // 가격 내림차순
    }
}
```

### 데이터 검색 및 필터링 (LINQ)
`LINQ`를 사용하면 복잡한 `foreach` 문 없이도 원하는 데이터를 빠르게 찾을 수 있습니다.

```csharp
// 가격이 100원 이상인 아이템만 추출
var expensiveItems = inventory.Where(item => item.price >= 100).ToList();

// 이름이 "포션"인 첫 번째 아이템 찾기 (없으면 null)
var potion = inventory.FirstOrDefault(item => item.name == "포션");

// 모든 아이템의 가격 합계 계산
int totalSum = inventory.Sum(item => item.price);
```

## 2. Dictionary<K, V>: 빠른 데이터 매핑

`List`는 순차적으로 데이터를 찾지만(O(n)), `Dictionary`는 키를 통해 즉시 데이터를 찾습니다(O(1)).

### 실무 활용: 아이템 데이터베이스
아이템 ID를 키로 사용하여 정보를 관리할 때 유용합니다.

```csharp
public class DataManager : MonoBehaviour {
    // Key: 아이템 ID, Value: 아이템 객체
    private Dictionary<int, Item> itemDb = new Dictionary<int, Item>();

    void Init() {
        itemDb.Add(101, new Item { name = "강철검", price = 500 });
        itemDb.Add(102, new Item { name = "회복물약", price = 50 });
    }

    public Item GetItem(int id) {
        if (itemDb.ContainsKey(id)) {
            return itemDb[id];
        }
        return null;
    }
}
```

## 3. Queue & Stack: 특수 목적 자료구조

### Queue<T> (First-In, First-Out)
- **활용**: 적 스폰 대기열, 메시지 로그 알림창.
```csharp
Queue<string> spawnQueue = new Queue<string>();
spawnQueue.Enqueue("Slime");
spawnQueue.Enqueue("Goblin");

string nextMonster = spawnQueue.Dequeue(); // 먼저 들어온 "Slime"이 나감
```

### Stack<T> (Last-In, First-Out)
- **활용**: UI 창 뒤로가기 시스템, 실행 취소(Undo).
```csharp
Stack<GameObject> uiStack = new Stack<GameObject>();

public void OpenWindow(GameObject win) {
    win.SetActive(true);
    uiStack.Push(win);
}

public void CloseRecentWindow() {
    if (uiStack.Count > 0) {
        GameObject top = uiStack.Pop();
        top.SetActive(false);
    }
}
```

## 4. 성능 최적화 팁

1. **Capacity 설정**: `List`나 `Dictionary`의 크기가 커질 때 내부적으로 배열 재할당이 발생하여 부하를 줍니다. 예상 크기를 알 수 있다면 미리 설정하세요.
   ```csharp
   List<int> largeList = new List<int>(1000); // 1000개의 공간을 미리 예약
   ```
2. **foreach vs for**: `List` 순회 시 `for`문이 아주 미세하게 더 빠르고 가비지가 적게 발생할 수 있습니다. (최신 C# 버전에서는 큰 차이가 없으나 대량 데이터 처리에선 고려 대상)
3. **LINQ 사용 주의**: `Update()` 문 안에서 LINQ를 매 프레임 사용하면 가비지 컬렉션(GC) 부하가 발생할 수 있습니다. 초기화(`Start`)나 이벤트 발생 시에만 사용하는 것이 좋습니다.
