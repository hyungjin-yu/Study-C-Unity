# Project Walkthrough: 인벤토리 및 이벤트 시스템

이 프로젝트는 `List`, `Dictionary`, `Singleton`, `Observer` 패턴을 하나로 결합하여 실전적인 유니티 시스템을 구축하는 예제입니다.

---

## 1. 시스템 구조도

1. **ItemData (ScriptableObject)**: 아이템의 원형 데이터 (ID, 이름, 가격).
2. **InventoryManager (Singleton)**: `Dictionary`로 모든 아이템 데이터를 관리하고, `List`로 현재 소지품을 관리.
3. **PlayerController**: 아이템 획득 시 `Action` 이벤트를 발생 (Observer).
4. **InventoryUI**: 이벤트를 구독하여 UI를 갱신.

---

## 2. 핵심 코드 구현

### [Item.cs] - 데이터 구조
```csharp
[System.Serializable]
public class Item {
    public int id;
    public string itemName;
    public int price;
}
```

### [InventoryManager.cs] - Singleton & Collections
```csharp
using System.Collections.Generic;
using UnityEngine;
using System.Linq;

public class InventoryManager : Singleton<InventoryManager> {
    // ID로 아이템을 빠르게 찾기 위한 사전
    private Dictionary<int, Item> itemDatabase = new Dictionary<int, Item>();
    
    // 현재 플레이어가 가진 아이템 리스트
    public List<Item> playerItems = new List<Item>();

    public void AddItem(Item newItem) {
        playerItems.Add(newItem);
        // 정렬: 이름순으로 자동 정렬
        playerItems = playerItems.OrderBy(x => x.itemName).ToList();
        
        // UI에 알림 (옵저버 패턴 활용 가능)
    }
}
```

### [GameEvents.cs] - Observer (Static Events)
```csharp
using System;

public static class GameEvents {
    // 아이템 획득 시 발생하는 이벤트
    public static Action OnInventoryUpdated;

    public static void TriggerInventoryUpdate() {
        OnInventoryUpdated?.Invoke();
    }
}
```

---

## 3. 실전 활용 시나리오

1. **아이템 획득**: 플레이어가 아이템과 충돌하면 `InventoryManager.Instance.AddItem()`을 호출합니다.
2. **이벤트 전파**: `AddItem` 로직 마지막에 `GameEvents.TriggerInventoryUpdate()`를 호출합니다.
3. **UI 갱신**: 인벤토리 UI 스크립트는 `OnEnable`에서 `GameEvents.OnInventoryUpdated += RefreshUI`를 통해 대기하다가, 이벤트가 오면 즉시 화면을 새로고침합니다.

---

## 4. 학습 마무리

- **List 계열이 약하다면?**: 데이터를 추가(`Add`), 삭제(`Remove`), 정렬(`OrderBy`), 검색(`FirstOrDefault`) 하는 과정을 반복 숙달하세요.
- **디자인 패턴이 어렵다면?**: 먼저 **싱글톤**으로 데이터를 한 곳에 모으고, **옵저버**로 필요한 곳에만 정보를 전달하는 습관을 들이세요. 클래스끼리 서로 `GetComponent`로 참조하는 것을 줄이는 것이 첫걸음입니다.
