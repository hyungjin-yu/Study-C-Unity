# Chapter 3: C# 프로퍼티 (get, set) 완벽 이해

프로퍼티는 클래스의 필드(변수)에 안전하게 접근하고, 값을 읽거나 쓸 때 추가적인 로직을 실행할 수 있게 해주는 C#의 강력한 기능입니다. 이를 **캡슐화(Encapsulation)**라고 합니다.

---

## 1. 왜 프로퍼티를 사용해야 하나요?

변수를 `public`으로 선언하면 어디서든 수정할 수 있어 편리하지만, 예상치 못한 버그를 유발할 수 있습니다.

### 문제 상황 (public 변수)
```csharp
public class Player {
    public int hp; // 외부에서 -1000 같은 비정상적인 값도 넣을 수 있음
}
```

### 해결책 (프로퍼티 활용)
```csharp
public class Player {
    private int _hp; // 실제 데이터 저장 (Backing Field)

    public int Hp {
        get { return _hp; }
        set {
            // 값이 0보다 작아지지 않도록 방어 로직 추가
            if (value < 0) _hp = 0;
            else _hp = value;
            Debug.Log($"현재 체력: {_hp}");
        }
    }
}
```

## 2. 프로퍼티의 다양한 형태

### (1) 자동 구현 프로퍼티 (Auto-Implemented Property)
특별한 로직 없이 값만 저장할 때 사용합니다. 코드가 매우 간결해집니다.
```csharp
public string PlayerName { get; set; }
```

### (2) 읽기 전용 프로퍼티 (Read-Only)
외부에서는 읽을 수만 있고, 수정은 클래스 내부에서만 가능하게 제한합니다. (유니티에서 가장 많이 권장되는 방식)
```csharp
public int Level { get; private set; } = 1;

public void LevelUp() {
    Level++; // 내부에서는 수정 가능
}
```

### (3) 계산된 프로퍼티 (Computed Property)
변수를 따로 두지 않고, 다른 값을 바탕으로 실시간으로 계산 결과를 반환합니다.
```csharp
public bool IsDead {
    get { return hp <= 0; }
}

// 위 코드는 아래와 같이 줄여 쓸 수 있습니다 (C# 6.0+)
public bool IsDead => hp <= 0;
```

## 3. 유니티 실무 활용: 옵저버 패턴과 결합

프로퍼티의 `set`을 활용하면 값이 바뀔 때마다 자동으로 이벤트를 발생시킬 수 있습니다.

```csharp
private int _score;
public int Score {
    get => _score;
    set {
        _score = value;
        // 점수가 바뀔 때마다 UI 업데이트 이벤트 호출!
        GameEvents.TriggerInventoryUpdate(); 
    }
}
```

---

## 💡 요약
- **get**: 값을 읽어올 때 실행됩니다.
- **set**: 값을 대입할 때 실행됩니다. `value`라는 키워드로 대입되는 값을 참조합니다.
- **private set**: "내 물건이니까 함부로 건드리지 마, 하지만 보여줄 수는 있어"라는 의미입니다.
