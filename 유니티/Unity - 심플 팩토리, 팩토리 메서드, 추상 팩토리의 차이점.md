
#심플팩토리 #팩토리메서드 #추상팩토리 #Unity


객체 생성 패턴은 복잡도와 유연성에 따라 크게 세 가지로 나뉩니다.

1. **심플 팩토리 (Simple Factory)**: 하나의 클래스가 조건에 따라 여러 객체를 생성합니다. 디자인 패턴의 기초가 되며 가장 단순합니다.
    
2. **팩토리 메서드 (Factory Method)**: 객체 생성을 하위 클래스에서 결정하도록 미룹니다. 특정 제품 하나를 만드는 공장들에 집중합니다.
    
3. **추상 팩토리 (Abstract Factory)**: 연관된 제품들의 '군(Family)'을 한꺼번에 생성합니다. 의존성을 완화하고 여러 객체를 세트로 관리하기 좋습니다.
    

### 💡 상황별 추천 패턴

- **심플 팩토리**: 생성할 객체의 종류가 적고, 단순히 생성을 한곳에 모으고 싶을 때 사용하세요.
    
- **팩토리 메서드**: 어떤 구체적인 객체가 생성될지 미리 알 수 없거나, 객체 생성 로직을 자식 클래스에서 자유롭게 확장하게 하고 싶을 때 적합합니다.
    
- **추상 팩토리**: 여러 종류의 관련 객체들(예: 윈도우용 버튼과 체크박스 세트)을 일관성 있게 생성해야 할 때 가장 강력합니다
