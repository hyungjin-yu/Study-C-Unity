
**빌더 패턴(Builder Pattern)**은 복잡한 객체를 단계별로 생성할 수 있도록 도와주는 생성 디자인 패턴입니다. 객체의 부품들을 먼저 만들고 이를 조합하여 전체를 완성하는 방식입니다.

### 🌟 주요 특징 및 장점

1. **생성자 비대화 방지**: 수많은 매개변수를 가진 생성자(Constructor) 대신, 메서드 체이닝을 통해 가독성 있게 객체를 설정할 수 있습니다.
    
2. **유연한 확장**: 플레이어 캐릭터의 옷, 무기, 스킬 등 커스터마이징이 필요한 복잡한 오브젝트를 작성할 때 매우 유용합니다.
    

### 🎮 유니티 활용 예시

- **캐릭터 생성**: 직업별 능력치, 장비 세팅을 단계별로 구성.
    
- **시스템 조립**: 로켓 발사 시스템의 엔진, 연료탱크 등을 조합하여 생성.
    

```
// 예시: 캐릭터 빌더
var player = new CharacterBuilder()
    .SetJob("Warrior")
    .SetWeapon("Sword")
    .SetArmor("Plate")
    .Build();
```

빌더 패턴을 사용하면 객체 생성 로직과 표현 로직을 분리하여 코드의 유지보수성을 높일 수 있습니다
