#디자인패턴 #행동패턴 #상태관리

**한 줄 요약 :** 객체의 내부 상태 변화에 따라 행동을 동적으로 변경하는 디자인 패턴

## 정의

상태 패턴을 사용하면 객체의 내부 상태가 바뀜에 따라 객체의 행동을 바꿀 수 있으며, 마치 객체의 클래스가 바뀌는 것과 같은 효과를 낸다. 
## 핵심 특징

- 각 상태를 클래스로 선언하고, 상태별 행위를 메서드로 정의
- 상태 전이(transition)가 존재하여 흐름이 있음

## 전략 패턴과의 차이

**상태 패턴:** 상태 간 전이가 있고 순서/흐름이 존재 (예: 결제 순서)  
**전략 패턴:** 임의의 상태를 다른 상태로 변경 (예: 결제 방법 선택)

## 구현 순서

1. State 인터페이스 정의
2. 구체적 상태 클래스 생성
3. Context 클래스에서 상태 변경 관리
