## 🗒️ Answer

### Asset 관리

- Asset은 Git에 계속 추가되면 안 됨
- `.gitignore` 파일 26번째 줄에서 Asset 주석 해제
- 다운받은 에셋이 있는 폴더명을 `.gitignore`에 추가

### Meta 파일의 중요성

**Meta 파일이란?**

- 세세한 인지적 정보를 담고 있는 파일
- Unity는 GUID를 통해 원본 파일의 위치를 추적 (Unity의 주소 개념)

**주의사항**

- Meta 파일 없이 원본만 올라가면 Unity가 파일을 인식하지 못함
- **커밋 시 반드시 원본 파일과 meta 파일이 함께 있는지 확인**
- 파일 미싱 에러 발생 시: Git에서 다운받은 파일에 meta 파일이 있는지, GUID가 일치하는지 확인
- 원본과 meta 파일의 위치를 변경해도 GUID는 변경되지 않음
- **파일 탐색기에서 직접 파일 이동/수정 금지** (Unity 에디터 내에서만 작업)

### 팀 프로젝트 대전제

**절대 규칙**

- 같은 파일에서 동시 작업 금지
- **특히 동일한 씬(Scene)에서 동시 작업 절대 금지**

**작업 방식**

1. 각 팀원마다 별도의 씬 생성
2. 개별 씬에서 기능 구현
3. 완료 후 병합 작업 진행
