### 🎯 핵심 개념

- **Composite Pattern 정의:**  
    객체를 트리 구조로 구성하여 개별 객체와 집합 객체를 동일하게 다룰 수 있도록 하는 디자인 패턴.

- **목표:**
- 계층적 구조를 단순화
- 개별 객체와 그룹 객체를 동일한 방식으로 처리

- **특징:**
- 재귀적 구조를 통해 복잡한 계층을 단순하게 표현
- 클라이언트 코드가 객체와 집합을 구분하지 않고 동일하게 사용 가능

---

### 🛠️ 구현 방식

1. **Component 인터페이스 정의**
- 공통 메서드 선언 (예: `Operation()`).

2. **Leaf 클래스 구현**
- 실제 기능을 수행하는 기본 객체.

3. **Composite 클래스 구현**
- 여러 Component를 포함하고, 자식 객체에 작업을 위임.

4. **클라이언트 코드**
- Leaf와 Composite를 동일하게 다루며 계층 구조를 관리.

---

### 🎮 Unity 활용 예시

- **UI 시스템:**
- 버튼, 패널, 윈도우 등을 트리 구조로 관리.

- **게임 오브젝트 계층:**
- 부모-자식 관계를 Composite로 표현.

- **스킬 시스템:**
- 기본 스킬과 복합 스킬을 동일한 방식으로 실행.

---

### ✅ 장점

- 객체와 집합을 동일하게 처리 가능
- 계층 구조 관리가 단순해짐
- 코드 재사용성과 확장성 강화

---

### ⚠️ 주의점

- 구조가 깊어지면 성능 저하 가능
- 지나치게 복잡한 트리 구조는 관리가 어려울 수 있음

---

### 📚 결론

- **Composite Pattern은 객체를 트리 구조로 관리하여 계층적 로직을 단순화하는 핵심 디자인 패턴**
- Unity에서 UI, 게임 오브젝트, 스킬 시스템 등 다양한 상황에 적용 가능
- 코드 유연성과 유지보수성을 높이는 데 유용
