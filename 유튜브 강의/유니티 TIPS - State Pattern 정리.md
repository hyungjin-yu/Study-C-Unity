### 🎯 핵심 개념

- **State Pattern 정의:**  
    객체의 내부 상태에 따라 행동을 변경할 수 있도록 구조화하는 디자인 패턴.

- **목표:**
- 조건문(if/switch) 남발을 줄이고
- 상태별 클래스로 분리하여 **확장성과 유지보수성** 확보.

- **특징:**
- 새로운 상태 추가가 용이
- 코드 가독성 향상
- Unity 프로젝트에서 캐릭터 동작, 게임 진행 상태 관리 등에 활용 가능

--- 

### 🛠️ 구현 방식

1. **State 인터페이스 정의**
- 공통 메서드(예: `Enter`, `Update`, `Exit`) 선언.

2. **구체 상태 클래스 구현**
- 각 상태별 동작을 별도 클래스로 작성.
- 예: `IdleState`, `MoveState`, `AttackState`.

3. **Context 클래스**
- 현재 상태를 참조하고, 상태 전환을 관리.
- `SetState()` 메서드로 상태 변경.

4. **상태 전환 로직**
- 이벤트나 조건 발생 시 Context가 새로운 상태로 교체.

--- 

### 🎮 Unity 활용 예시

- **캐릭터 제어:**
- Idle → Move → Attack → Die 등 상태 전환.

- **게임 진행:**
- MainMenu → Playing → Paused → GameOver.

- **UI 관리:**
- 버튼 클릭 시 상태별 화면 전환.

### ✅ 장점

- 조건문 복잡성 감소
- 상태 추가/변경 시 기존 코드 영향 최소화
- 테스트 및 디버깅 용이
- Unity 프로젝트에서 **모듈화된 구조** 제공

### 📚 결론

- **State Pattern은 확장성과 유지보수성을 높이는 핵심 디자인 패턴**
- Unity에서 캐릭터 동작, 게임 상태, UI 관리 등 다양한 상황에 적용 가능
- 실무에서 코드 품질을 높이고 협업 효율성을 개선하는 데 유용
