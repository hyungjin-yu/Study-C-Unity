### 🎯 핵심 개념

- **Decorator Pattern 정의:**  
    객체에 새로운 기능을 덧붙여 확장할 수 있도록 하는 구조적 디자인 패턴.

- **목표:**
- 상속 대신 합성을 통해 기능 확장
- 런타임에 동적으로 기능을 추가 가능

- **특징:**
- 기본 객체를 감싸는 래퍼(wrapper) 구조
- 여러 데코레이터를 조합해 다양한 기능 구현

---

### 🛠️ 구현 방식

1. **Component 인터페이스 정의**
- 공통 메서드 선언 (예: `Operation()`).

2. **Concrete Component 클래스 구현**
- 기본 기능을 제공하는 클래스 작성.

3. **Decorator 클래스 작성**
- Component를 참조하고, 기능을 덧붙여 확장.

4. **Concrete Decorator 구현**
- 실제로 새로운 기능을 추가하는 클래스 작성.

---

### 🎮 Unity 활용 예시

- **무기 시스템:**
- 기본 무기에 `FireDecorator`, `PoisonDecorator` 등을 덧붙여 다양한 효과 구현.

- **UI 요소:**
- 버튼에 애니메이션, 사운드 효과를 데코레이터로 추가.

- **캐릭터 능력:**
- 기본 캐릭터에 버프/디버프 기능을 데코레이터로 적용.

---

### ✅ 장점

- 상속보다 유연한 기능 확장
- 런타임에 기능 추가 가능
- 여러 데코레이터를 조합해 다양한 기능 구현
- 코드 재사용성 강화

---

### ⚠️ 주의점

- 데코레이터가 많아지면 구조가 복잡해질 수 있음
- 디버깅 시 래퍼 체인을 추적하기 어려울 수 있음

---

### 📚 결론

- **Decorator Pattern은 객체에 동적으로 기능을 추가할 수 있는 강력한 디자인 패턴**
- Unity에서 무기, UI, 캐릭터 능력 등 다양한 상황에 적용 가능
- 상속의 한계를 극복하고 코드 유연성을 높이는 데 유용
