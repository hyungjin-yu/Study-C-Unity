### 🎯 핵심 개념

- **Observer Pattern 정의:**  
    객체의 상태 변화나 액션을 다른 객체(옵저버)에게 자동으로 알리고 반응할 수 있도록 하는 디자인 패턴.
- **구성 요소:**

- **Subject(주체):** 상태 변화를 발생시키는 객체
- **Observer(관찰자):** Subject의 변화를 감지하고 반응하는 객체

- **Unity 적용:**  
    UnityEvent를 활용해 느슨한 결합(loose coupling)을 유지하면서 이벤트를 전달

--- 

### 🛠️ 구현 방식

1. **Subject 클래스**
- 이벤트를 정의하고, 옵저버가 등록/해제할 수 있도록 관리.

2. **Observer 클래스**
- Subject의 이벤트를 구독하고, 이벤트 발생 시 반응하는 로직 작성.

3. **UnityEvent 활용**
- Inspector에서 이벤트 연결 가능 → 코드 수정 없이 다양한 반응 구현.

---

### 🎮 Unity 활용 예시

- **UI 버튼 클릭 이벤트:**
- 버튼 클릭 시 여러 오브젝트가 동시에 반응.

- **게임 진행 로직:**
- 플레이어 HP 변화 → UI 업데이트, 사운드 재생, 애니메이션 실행.

- **멀티 이벤트 처리:**
- 하나의 Subject가 여러 Observer에게 알림을 전달.

--- 

### ✅ 장점

- 느슨한 결합으로 코드 유연성 확보
- 새로운 Observer 추가/삭제가 용이
- 이벤트 기반 구조로 확장성 강화
- UnityEvent로 직관적인 이벤트 연결 가능

--- 

### ⚠️ 주의점

- 남용 시 디버깅이 어려워질 수 있음
- 이벤트 체인이 복잡해지면 관리가 힘들어질 수 있음

---

### 📚 결론

- **Observer Pattern은 이벤트 기반 로직을 깔끔하게 구현하는 핵심 디자인 패턴**
- Unity에서 UI, 게임 진행, 오브젝트 상호작용 등 다양한 상황에 적용 가능
- 느슨한 결합을 통해 유지보수성과 확장성을 높일 수 있음
