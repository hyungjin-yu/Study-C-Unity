### 🎯 핵심 개념

- **Flyweight Pattern 정의:**  
    공유 가능한 객체를 분리하여 메모리 사용을 줄이는 디자인 패턴.

- **목표:**
- 대량의 객체 생성 시 메모리 낭비 방지
- 공통 속성은 공유, 개별 속성만 별도로 관리

- **특징:**
- Intrinsic State(내부 상태): 공유 가능한 불변 데이터
- Extrinsic State(외부 상태): 개별 객체가 가지는 고유 데이터

---

### 🛠️ 구현 방식

1. **Flyweight 인터페이스 정의**
- 공통 기능을 선언.

2. **Concrete Flyweight 클래스 구현**
- 공유 가능한 속성을 관리.

3. **Flyweight Factory 작성**
- 동일한 속성을 가진 객체를 재사용하도록 관리.

4. **클라이언트 코드**
- Factory를 통해 Flyweight 객체를 요청하고, 외부 상태를 함께 전달.

---

### 🎮 Unity 활용 예시

- **총알(Bullet) 관리:**
- 동일한 Mesh/Material을 공유, 위치/속도만 개별 관리.

- **타일맵(Tilemap):**
- 같은 그래픽 리소스를 공유, 좌표만 다르게 적용.

- **NPC 외형:**
- 동일한 모델을 공유, 개별 데이터(이름, 위치)만 관리.

---

### ✅ 장점

- 메모리 사용량 크게 절감
- 대량 객체 관리에 효율적
- 성능 최적화에 유리

---

### ⚠️ 주의점

- 구현이 복잡해질 수 있음
- 공유와 개별 상태를 잘못 관리하면 버그 발생 가능

---

### 📚 결론

- **Flyweight Pattern은 대량 객체를 효율적으로 관리해 메모리를 절약하는 핵심 디자인 패턴**
- Unity에서 총알, 타일맵, NPC 등 반복되는 리소스 관리에 적합
- 성능 최적화가 필요한 대규모 프로젝트에서 특히 유용
